# План: трекер дедлайнов по учёбе (Python + FastAPI)

*Составлено вместе с Claude, 15 октября 2026. Шаги 2–7 уточняем по ходу работы.*

## Зачем этот проект

За 3–4 недели сделать работающий веб-трекер дедлайнов, которым пользуешься сам и который открывается по ссылке с чужого телефона. После проекта честно ответить себе: что было интереснее, писать логику и интерфейс (backend/fullstack) или возиться с серверами и деплоем (DevOps). Это поможет выбрать направление не по таблицам зарплат, а по реальному опыту.

## Стек

Python, FastAPI, SQLite, HTML/CSS/JavaScript, Git и GitHub, Docker, VPS.

## Как работаем

- Код пишу **сам**. Claude даёт задачу, названия нужных инструментов, где читать и контрольную точку.
- Примеры из официальной документации использовать можно, но каждую строку я должен уметь объяснить и изменить под свою задачу.
- Закончил шаг: отправляю Claude свой код и объясняю своими словами, что делает каждая часть. Claude ищет ошибки и подсказывает, как лучше.
- Застрял больше чем на 30 минут: прошу минимальный кусок именно того места, где затык. Присылаю текст ошибки целиком и свой код.
- Коммит на GitHub каждый день, даже маленький.
- В README две строки: что это и как запустить.
- Лучше уродливое приложение, которое работает по ссылке, чем идеальное, которое лежит на диске.

## Шаг 1. Подготовка (неделя 1)

**Выучить:**
- Python: переменные, условия, циклы, функции, списки и словари, работа с файлами, базовые классы, `pip` и виртуальные окружения (`venv`).
- Git: `init`, `add`, `commit`, `push`, ветки. Тренажёр: learngitbranching.js.org.
- Командная строка: перемещаться по папкам, создавать и удалять файлы, запускать скрипты.

**Задачи** (команды для Windows, PowerShell):
- [ ] Python 3.10 или новее: проверить `python --version`; если нет, поставить с python.org с галочкой «Add Python to PATH»
- [ ] VS Code и расширение «Python» от Microsoft
- [ ] Git (git-scm.com), затем `git config --global user.name "Имя"` и `git config --global user.email "почта"`
- [ ] Аккаунт на github.com
- [ ] Репозиторий `study-tracker` (публичный, с README)
- [ ] `git clone https://github.com/ТВОЙ_НИК/study-tracker.git`, затем `cd study-tracker`
- [ ] Виртуальное окружение: `python -m venv .venv`, затем `.venv\Scripts\Activate.ps1` (если PowerShell ругается: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`)
- [ ] `pip install "fastapi[standard]"`
- [ ] Файл `main.py`: FastAPI-приложение с одним маршрутом на `/`, который отдаёт JSON с сообщением. Писать самому: нужны класс `FastAPI`, декоратор `@app.get(...)` и функция, возвращающая словарь
- [ ] Запуск `fastapi dev main.py`, проверить `127.0.0.1:8000` и страницу `/docs`
- [ ] `.gitignore` со строками `.venv/` и `__pycache__/`, затем `git add .`, `git commit`, `git push`
- [ ] Объяснить Claude своими словами каждую строку `main.py`, особенно что такое декоратор

**Где читать:** официальный туториал FastAPI, раздел «First Steps» (fastapi.tiangolo.com).

**Контрольная точка:** вижу сообщение в браузере и страницу `/docs`, коммит виден на GitHub.

## Шаг 2. База данных (неделя 2)

**Выучить:** SQL (`SELECT`, `INSERT`, `UPDATE`, `DELETE`, `WHERE`, `ORDER BY`), что такое таблица, строка, первичный ключ. Модуль `sqlite3` из стандартной библиотеки Python.

**Задачи:**
- [ ] Самому продумать таблицу задач: какие нужны поля (идея: название, предмет, дедлайн, выполнено) и какие у них типы
- [ ] Создать базу и таблицу из Python-скрипта через `sqlite3`
- [ ] Руками добавить, прочитать, изменить и удалить несколько записей SQL-запросами
- [ ] Показать Claude схему таблицы на проверку

**Где читать:** документация Python, модуль `sqlite3` (docs.python.org/3/library/sqlite3.html); любой интерактивный SQL-тренажёр.

**Контрольная точка:** файл базы с таблицей и тестовыми данными, умею выбрать задачи по условию.
